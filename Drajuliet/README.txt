# Site — Juliet Cesário Lage

Site estático responsivo pronto para publicar no GitHub Pages.

## Publicação
1. Extraia o ZIP.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório GitHub.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

## Formulário
O formulário monta a mensagem e abre o WhatsApp informado no perfil fornecido. O visitante precisa tocar em **Enviar** no WhatsApp para concluir o contato. Não há armazenamento de dados nem envio automático por servidor.

## Antes de publicar
- Confirme se o número de WhatsApp `5535196571639` está correto.
- A imagem fornecida foi mantida sem retoques; como o arquivo original é uma foto circular com elementos gráficos sobrepostos, esses elementos permanecem na imagem.
- Não foram incluídos depoimentos fictícios, endereço ou credenciais não confirmadas.
